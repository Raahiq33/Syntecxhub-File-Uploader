# 📁 Syntecxhub File Uploader

A simple full-stack File Upload and Management application built using Node.js, Express.js, MongoDB Atlas, GridFS, HTML, CSS, and JavaScript.

This project allows users to upload, view, list, and delete files through a simple web interface.

## 🚀 Features

- Upload files to MongoDB using GridFS
- View uploaded files
- Delete uploaded files
- Display uploaded file name and size
- Maximum file size: 5MB
- File type validation
- Supports PDF, JPG, JPEG, PNG, and DOCX
- Error handling for invalid files
- Simple and responsive user interface
- MongoDB Atlas cloud database integration

## 🛠️ Technologies Used

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- GridFS
- Multer
- CORS
- dotenv

### Frontend
- HTML5
- CSS3
- JavaScript
- Fetch API
